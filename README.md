# 📋 智简简历 - 免费在线简历生成器

**链接：https://resume-builder-gamma-silk.vercel.app**

## ✨ 功能特点

- 🎨 **3套精美模板**：经典 / 现代 / 创意，一键切换
- 👀 **实时预览**：左边填信息，右边即时看到简历效果
- 📥 **一键导出PDF**：浏览器直接打印导出，无需安装任何软件
- 📱 **移动端适配**：手机上也能编辑简历
- 🆓 **完全免费**：无需注册，打开即用
- 🔒 **隐私安全**：所有数据在浏览器本地处理，不上传任何服务器

## 🎯 适合谁用

- 找工作的应届生 / 社招跳槽者
- 需要快速制作一份专业简历的人
- 不想花钱买简历模板的求职者

## 💡 使用方法

1. 打开网站
2. 在左侧填写个人信息（姓名、联系方式、教育经历、工作经历等）
3. 右侧实时预览简历效果
4. 选择喜欢的模板风格
5. 点击"导出PDF"按钮保存

就是这么简单！

## 🛠 技术实现

纯前端实现，零后端依赖：
- HTML / CSS / JavaScript
- 实时渲染预览
- 浏览器原生打印API导出PDF
- 部署在 Vercel（免费）
